HOW IT WORKS
================================================================================

FLOW: LlamaFarm Training → Mesh Dissemination

1. LlamaFarm trains new vision model (user escalates → replay buffer → train)
   
2. Create package:
   POST /v1/vision/federation/packages {"model_id": "..."}
   → Exports model.pt + metadata.json + class_map.json as .tar.gz

3. Python ModelBridge discovers (every 5 min):
   GET /v1/vision/models          → active models
   GET /v1/vision/federation/packages  → packages with metadata
   → Updates internal catalog

4. ModelBridge gossips to mesh:
   {
     "type": "model_catalog",
     "node_id": "llamafarm-primary",
     "models": [{...}, {...}],
     "transfer_endpoints": {"http": "http://192.168.1.100:14345"}
   }

5. Android GossipManager receives gossip:
   → Routes to ModelCatalog.processCatalogMessage()
   → ModelCatalog merges peer availability info

6. MeshCapabilityHandler checks for updates:
   → Compares local version vs. gossip version
   → If newer: selects best peer (HTTP preferred, low latency)
   → Queues download via ModelTransferService

7. ModelBridge serves download:
   GET /v1/models/download/{model_id}
   → HTTP Range support for resumable transfer
   → 64KB chunks

8. Android VisionModelManager imports:
   → Verifies SHA-256 checksum
   → Extracts package
   → Loads model.pt for inference

9. Device announces capability:
   {
     "type": "capability_announce",
     "vision_models": [{"model_id": "...", "version": "1.0.0", "loaded": true}]
   }

10. Model now available for mesh-wide inference!

MESSAGE FORMATS
================================================================================

model_catalog (Python → Android/Mac):
{
  "type": "model_catalog",
  "node_id": "llamafarm-primary",
  "node_name": "LlamaFarm",
  "timestamp": 1234567890,
  "models": [
    {
      "model_id": "yolov8n_custom_20240208",
      "name": "Custom YOLOv8n",
      "type": "vision",
      "format": "pt",
      "size_bytes": 6000000,
      "sha256": "abc123...",
      "version": "1.0.0",
      "capabilities": ["object_detection"],
      "classes": ["person", "car", "dog"],
      "class_count": 3,
      "source": "llamafarm_training"
    }
  ],
  "transfer_endpoints": {
    "http": "http://192.168.1.100:14345",
    "websocket": true
  },
  "ttl_seconds": 300
}

capability_announce (Android/Mac → Mesh):
{
  "type": "capability_announce",
  "node_id": "android_device_123",
  "capabilities": [...],
  "vision_models": [
    {
      "model_id": "yolov8n_custom_20240208",
      "version": "1.0.0",
      "loaded": true
    }
  ]
}

KEY FEATURES
================================================================================

✅ Automatic Model Discovery
   - Python scans LlamaFarm every 5 minutes
   - No manual intervention required

✅ Mesh-Wide Gossip
   - Model availability propagates automatically
   - TTL-based expiration (5 minutes)
   - Nonce-based deduplication

✅ Smart Download Selection
   - Prefers HTTP over WebSocket (faster, resumable)
   - Considers peer latency
   - Tracks peer reliability

✅ Resumable Downloads
   - HTTP Range support
   - Can resume interrupted transfers
   - Chunked verification

✅ Version Management
   - Semantic versioning comparison
   - Auto-detects newer versions
   - Triggers updates automatically

✅ Integrity Verification
   - SHA-256 checksums
   - Per-chunk validation
   - Reject corrupted downloads

✅ Multi-Platform Support
   - Python ModelBridge (Linux/Mac/Windows)
   - Android native (Kotlin)
   - Mac native (Swift)
